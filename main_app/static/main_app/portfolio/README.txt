Digital Dizzles Portfolio
=========================

To open the portfolio:

1. Double-click open-portfolio.bat
2. Your browser should open this address:
   http://127.0.0.1:4173/index.html
3. Keep the server window open while viewing the site.

If the browser does not open automatically, copy this address into your browser:
http://127.0.0.1:4173/index.html
